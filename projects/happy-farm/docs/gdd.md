## 一句话定位

- 项目 ID：`happy-farm`
- 游戏名称：开心农场（Happy Farm）
- 品类：休闲模拟经营 / 社交农场（casual farming sim）
- 核心体验（一句话）：种菜 → 收获 → 卖钱 → 扩建 → 串门互助，轻松治愈的田园经营循环。

## 目标用户与卖点

- 目标用户：全年龄休闲玩家，碎片时间游玩，偏好治愈 / 收集 / 轻社交；女性与家庭用户占比高。
- 核心卖点（3 条以内）：
  1. 低门槛治愈种植：一键播种 / 收获，离线也能生长，无压力。
  2. 轻社交互访：好友农场串门、帮忙浇水 / 趣味偷菜，异步温暖互动。
  3. 收集与装扮：作物图鉴、农场装饰、季节限定内容。
- 竞品差异（不抄袭，只比品类体验）：比 Hay Day 更轻、更社交化（互助 / 偷菜）；比 QQ农场更现代的移动端横屏体验。仅比品类体验，不复刻具体美术与数值。

## 核心循环

```text
登录/回流 → 准备 → 核心玩法 → 结算成长 → 商业补给 → 回流
```

| 环节 | 玩家目标 | 主要界面 | 成功标准 |
|---|---|---|---|
| 回流 | 领取离线收益、看红点 | farm | 领取离线金币，进入农田 |
| 准备 | 选种、整地 | farm / shop | 买到种子、清空地块 |
| 核心玩法 | 播种 / 浇水 / 收获 | farm | 完成一块地「种植 → 收获」 |
| 结算成长 | 卖作物、升级 | barn / farm | 入库 → 出售 → 金币 / 经验增加 |
| 商业补给 | 补种子、加速 | shop | 购买种子 / 道具，货币扣减 |

## 资源与经济（策划层）

- 软通货：金币（coin）——卖作物 / 任务获得，用于买种子 / 装饰。
- 硬通货：钻石（gem）——付费 / 成就获得，用于加速 / 稀有种子。
- 体力/行动力：体力（energy）——浇水 / 串门消耗，随时间恢复。
- 掉落与产出节奏（概述，不写服务端公式）：作物按现实时间生长（分钟 ~ 小时），离线累积；地块等级越高产出越快。
- 禁止在本阶段假装已完成真实支付与服务端校验。

## 进度与养成

- 角色/卡牌成长轴：农场等级（经验解锁新地块 / 新作物）。
- 关卡/挑战进度轴：地块扩建 + 作物图鉴收集度。
- 日常/周常回流钩子：每日任务、离线收益、好友互助、季节限定。

## 叙事与世界观（UI 所需最小集）

- 时代/气质：现代治愈田园，Q版卡通，明亮饱和、圆润可爱。
- 势力或阵营（如有）：无；以好友 / 邻居社区关系为主。
- UI 文案语气：亲切、轻松、鼓励，短中文。
