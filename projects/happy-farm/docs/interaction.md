## 全局交互原则

- 触控热区：主按钮高度 ≥ 88px（1792×1024 基准）；图标可点区域 ≥ 80×80px。
- 反馈层级：点击态（按下缩放/变暗）→ 结果反馈（飘字/动效）→ 异常提示（toast/横幅）。
- 主操作对比强于次操作；破坏性 / 付费操作需二次确认。
- 动效：短反馈优先（≤ 300ms）；提供减少动效时的静态替代。
- 文案：短中文；组件素材默认无字，文案运行时叠加。

## 全局导航

```text
顶部资源条（金币 | 钻石 | 体力 + 头像/等级）常驻

右上角：settings 齿轮入口（全屏模态）
```

| 入口 | 目标页 | 高亮规则 | 红点规则 |
|---|---|---|---|
| farm tab | farm | 当前页描边高亮 | 有可收获作物 |
| shop tab | shop | 当前页描边高亮 | 有限时折扣 |
| barn tab | barn | 当前页描边高亮 | 仓库将满 |
| social tab | social | 当前页描边高亮 | 有好友互助请求 |
| task tab | task | 当前页描边高亮 | 有可领奖励 |
| settings 齿轮 | settings | 模态打开态 | 无 |

## 全局状态

| 状态 | 触发 | UI 表现 | 恢复 |
|---|---|---|---|
| loading | 切页 / 拉数据 | 骨架屏 + 加载图标 | 数据就绪 → default |
| offline | 网络失败 | 顶部 offline 横幅 + 重试 | 重试成功 → default |

| empty | 列表无内容 | 空态插画 + 引导按钮 | 产生数据 → default |

## 分页面交互

### `farm`（农田主页）

- 目的：核心种植玩法主界面，承载播种 / 浇水 / 收获 / 离线收益。
- 进入来源：启动默认页 / 底部 farm tab / 好友农场返回。
- 离开去向：shop / barn / social / task / settings。

#### 主流程

```text
进入 → 见农田地块 + 顶部资源条 → 点空地播种 → 选种子 → 浇水 → 等待/加速 → 收获 → 入库飘字 → 停留
```

#### 控件与行为

| 控件 | 操作 | 前置条件 | 成功结果 | 失败/空态 |
|---|---|---|---|---|
| 地块 | tap | 空地 | 打开种子选择 | 无种子 → 去 shop |
| 种子项 | tap | 有种子 | 播种成功，地块变幼苗 | 种子不足 → 去 shop |
| 浇水按钮 | tap | 体力>0 | 生长加速 | 体力不足 → 恢复倒计时 |
| 收获按钮 | tap | 作物成熟 | 入库 + 金币/经验飘字 | 未成熟 → 显示倒计时 |
| 离线收益弹窗 | tap 领取 | 有离线产出 | 金币入账 | 无 → 不弹 |

#### 状态机

| 状态 | 可见内容 | 可点操作 | 切换条件 |
|---|---|---|---|
| default | 农田 + 资源条 + tab | 播种/浇水/收获 | — |
| incomplete | 新手引导高亮第一块地 | 引导播种 | 完成首次播种 |
| low-currency | 资源条红色 | 去商店 | 货币补足 |
| loading | 骨架屏 | 无 | 数据就绪 |

#### 弹窗 / 二次确认

| 场景 | 文案要点 | 确认 | 取消 |
|---|---|---|---|
| 钻石加速 | 消耗 N 钻石立即成熟 | 加速 | 返回 |
| 离线收益 | 离线期间产出金币 | 领取 | 关闭 |

#### 与视觉稿的约束

- 首屏必须露出的信息：金币 / 钻石 / 体力、至少 6 块农田、底部 tab。
- 禁止遮挡的区域：顶部资源条、底部 tab、中央农田网格。
- 生图需强调的主操作：成熟地块的「收获」高亮按钮。

### `shop`（商店）

- 目的：购买种子 / 道具 / 装饰。
- 进入来源：底部 shop tab / 资源不足「去商店」。
- 离开去向：购买确认模态 → 返回 farm / barn。

#### 主流程

```text
进入 → 见分类 tab（种子/道具/装饰）+ 商品网格 → 选商品 → 详情/价格 → 购买确认 → 货币扣减 → 入库反馈
```

#### 控件与行为

| 控件 | 操作 | 前置条件 | 成功结果 | 失败/空态 |
|---|---|---|---|---|
| 分类 tab | tap | — | 切换商品列表 | — |
| 商品卡 | tap | — | 打开详情 | — |
| 购买按钮 | tap | 货币足 | 扣减 + 入库 toast | 不足 → low-currency |
| 数量步进 | tap | — | 调整数量与总价 | 超上限置灰 |

#### 状态机

| 状态 | 可见内容 | 可点操作 | 切换条件 |
|---|---|---|---|
| default | 分类 + 商品网格 | 选品/购买 | — |
| low-currency | 价格红色 + 不足提示 | 去充值/返回 | 货币补足 |
| empty | 该分类无商品 | 切分类 | 上架 |

#### 弹窗 / 二次确认

| 场景 | 文案要点 | 确认 | 取消 |
|---|---|---|---|
| 钻石购买 | 消耗 N 钻石购买 X | 确认购买 | 取消 |
| 金币购买 | 消耗 N 金币 | 确认 | 取消 |

#### 与视觉稿的约束

- 首屏必须露出的信息：分类 tab、≥ 6 商品卡、价格与货币图标。
- 禁止遮挡的区域：顶部资源条、分类 tab、底部 tab。
- 生图需强调的主操作：商品卡上的「购买」按钮。

| 分类筛选 | tap | — | 过滤作物/道具 | — |
| 图鉴入口 | tap | — | 打开图鉴（P1） | — |

#### 状态机

| 状态 | 可见内容 | 可点操作 | 切换条件 |
|---|---|---|---|
| default | 物品网格 + 容量条 | 选择/出售 | — |

#### 弹窗 / 二次确认

| 场景 | 文案要点 | 确认 | 取消 |
|---|---|---|---|
| 批量出售 | 出售 N 件得 X 金币 | 确认出售 | 取消 |

#### 状态机

| 状态 | 可见内容 | 可点操作 | 切换条件 |

## 跨页链路（核心循环相关）

1. farm（播种）→ shop（买种子）→ 购买确认 → farm（播种成功）。
2. farm（收获）→ barn（入库）→ 出售确认 → 金币增加 → farm。
3. farm → social（串门）→ 好友农场（浇水/偷菜）→ farm。
4. task（领取）→ 奖励弹窗 → 资源条更新 → farm。
5. 任意页 → settings（模态）→ 关闭 → 原页。
