## 概述

- 项目 ID：`happy-farm`
- 产品目标：交付一套可复现、可引擎接入的「开心农场」横屏 UI——6 个核心屏幕 + 组件库 + Atlas + 引擎 JSON + web catalog。
- 成功指标（可验证）：
  1. 6 个 must-have 屏幕均有视觉稿与交互状态定义。
  2. 组件库覆盖核心控件，9-slice / Atlas / 引擎 JSON 三者一致。
  3. `kui validate specs/happy-farm --strict --json` → `exit_code=0`。
- 非目标（明确不做）：不做服务端 / 真实支付 / 后端数值；不做登录 SDK 接入；不做 3D 渲染。

## 用户与场景

| 角色 | 目标 | 关键场景 |
|---|---|---|
| 新玩家 | 快速上手种植 | 首次进入 farm，引导播种第一块地 |
| 回流玩家 | 领离线收益继续经营 | farm 离线结算弹窗 → 一键领取 |
| 付费玩家 | 加速 / 稀有装饰 | shop 钻石购买 → 二次确认 |

## 文案与本地化

- 默认语言：简体中文。
- 文案原则（短、可读、禁乱码占位）：运行时叠加文案，单条 ≤ 8 字优先。
- 生图策略：页面用 text-free base + 标注文案区（CJK 易乱码，不声称乱码可交付）；组件雪碧图默认无文字。

## 数据依赖（客户端可见）

| 数据 | 用途页面 | 空态/异常 |
|---|---|---|
| wallet | farm / shop / barn | 余额不足提示 + 去商店 |

| friends | social | 无好友态 + 邀请入口 |
| tasks | task | 无可领任务态 |

## 边界与异常

- 网络失败：顶部 offline 横幅 + 重试按钮。
- 资源不足：购买 / 播种按钮置灰 + 不足提示 + 去商店链路。
- 冷却/次数耗尽：体力不足提示 + 恢复倒计时。
- 新手引导打断：可跳过，记录引导进度。
