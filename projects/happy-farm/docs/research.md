# UI 研究记录

## 研究范围

- 项目 ID：`happy-farm`
- 分析对象：农场经营品类（Hay Day / 卡通农场 / QQ农场）的通识视觉抽象；用户未提供具体参考图。
- 研究目标：提炼可复用的视觉模式与设计令牌，支撑横屏 16:9 的 Q版卡通田园 UI。

## 参考图视觉抽象

- 色彩与对比：高饱和暖色基调（草绿 / 麦黄 / 天蓝），主操作用暖橙突出，背景明亮低对比。
- 材质与纹理：手绘卡通质感，木纹 / 草地 / 泥土纹理；圆润造型、厚描边。
- 光源与阴影：左上柔和光（top-left, soft），软投影，避免硬阴影。
- 圆角、描边与厚度：大圆角（卡片 20 / 模态 28），描边 4–6px，按钮厚实有体积感。
- 构图密度：中等；农田网格留白充足，列表区紧凑。
- 图标视角：正面微俯（2.5D），统一描边与视角。
- 字体气质：圆润无衬线，粗标题，数字醒目。

## 可复用模式

- 导航模式：底部主 tab（farm/shop/barn/social/task）+ 顶部常驻资源条 + 右上设置齿轮。
- 卡片模式：圆角卡片 + 厚描边 + 软投影 + 图标左 / 文案右。
- 反馈模式：飘字（金币 / 经验）+ toast（异常）+ 二次确认模态（付费 / 破坏性）。
- 信息层级：资源条 > 主操作 > 列表内容 > 次级入口。

## 玩家旅程与核心循环

1. 首次进入：farm 新手引导高亮第一块地 → 播种。
2. 准备：shop 买种子 → farm 整地播种。
3. 核心玩法：浇水 / 等待 / 加速 → 收获。
4. 结算与成长：barn 入库 → 出售 → 金币 / 经验 → 升级解锁地块。
5. 日常回流：离线收益 + task 每日奖励 + social 互助。

## 风险与约束

- 版权与品牌：原创美术，不复刻竞品具体角色 / 商标。
- 文字生成：CJK 易乱码 → 页面用 text-free base + 标注文案区，组件无字，文案运行时叠加。
- 平台安全区：横屏刘海 / 圆角安全区，顶部资源条与底部 tab 留安全边距。
- 复杂度与开发成本：组件化复用，控制生图数量；先 6 屏 + 核心组件库。

## 决策

- 采用：Q版卡通田园风格、横屏 16:9（1792×1024）、底部 tab 导航、text-free 生图策略、暖橙主操作色。
- 拒绝：像素风 / 国风（用户选 Q版卡通）、竖屏（用户选横屏）、真实商标素材。
- 原因：用户明确确认平台与风格；其余为品类适配的可调整默认。
