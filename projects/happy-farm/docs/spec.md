# UI 项目规格

## 项目定位

- 项目 ID：`happy-farm`
- 游戏名称：开心农场（Happy Farm）
- 游戏类型：休闲模拟经营 / 社交农场
- 核心玩法：种植 → 收获 → 出售 → 扩建 → 社交互助
- 目标平台：mobile（手机横屏）
- 画面比例：16:9（基准 1792×1024）
- 目标用户：全年龄休闲玩家，碎片时间，偏好治愈 / 收集 / 轻社交
- 文案语言：简体中文

## 输入资料

- 参考图片：无（用户未提供；以农场经营品类通识做视觉抽象）
- 现有页面：无（新建项目）
- 品牌或版权限制：原创美术；禁用真实商标 / 竞品素材复刻

## 用户故事

### US-01

作为一名休闲玩家，我希望一键播种并收获作物，从而利用碎片时间轻松经营农场。

验收场景：

1. Given 有空地与种子 When 点击空地选种 Then 播种成功并显示生长倒计时。
2. Given 作物成熟 When 点击收获 Then 入库并飘字金币 / 经验。

### US-02

作为一名回流玩家，我希望领取离线收益，从而感受到农场持续生长的治愈感。

验收场景：

1. Given 有离线产出 When 进入 farm Then 弹离线收益并一键领取金币。

### US-03

作为一名社交玩家，我希望串门帮好友浇水，从而获得友情点与轻互动乐趣。

验收场景：

1. Given 有好友 When 进入 social 选好友 Then 进入其农场并浇水获得友情点。

## 范围

### 包含

- 6 个核心屏幕：farm / shop / barn / social / task / settings。
- 复用组件库（按钮 / 面板 / 资源条 / 物品格 / 作物图标 / 进度条 / tab / 弹窗等）。
- 雪碧图切分、9-slice、Atlas、引擎 JSON（godot / unity / cocos / generic / taptap-maker）。
- web catalog（index.html / result.html）与复现说明。

### 不包含

- 服务端 / 真实支付 / 后端数值公式。
- 登录 SDK 接入、3D 渲染。
- decor / season / login 的正式视觉（列为可选，仅契约预留）。

## 视觉目标

- 情绪：治愈、明亮、温暖、轻松。
- 风格关键词：Q版卡通、田园、圆润、高饱和、手绘质感、厚描边。
- 识别性目标：一眼识别为农场经营（作物 / 地块 / 谷仓 / 资源条）。
- 可读性目标：主操作 3 秒内可识别；顶部资源条常驻清晰。

## 页面范围

- 首个生成页面：farm
- 必须延展的系统：farm / shop / barn / social / task / settings
- 可选系统：decor / season / login
