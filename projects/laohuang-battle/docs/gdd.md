## One-Line Positioning

- Project ID: `laohuang-battle`
- Game title: 老黄的战斗
- Genre: 单机肉鸽卡牌构筑（Roguelike Deckbuilder），山路推进 + 三选一构筑 + 回合制对阵
- Core experience (one line): 五十三岁的老黄，一件皮衣一把算力刀，为了把被少庄主抬上山的阿岚抢回来，从山脚一路打到山顶，连挑九个情敌。

## Target Audience & Selling Points

- Target audience: 25–40 岁、玩过《杀戮尖塔》类构筑肉鸽、偏好单局 15–25 分钟、厌烦联网与氪金的中文玩家为主
- Core selling points (up to 3):
  1. **九个情敌，一人一句嘲讽**：每关三位情敌，关底是有名字、有脾气、有专属台词的头目；打完能「拿走他身上一样东西」当刀诀
  2. **刀诀拼装**：每战后三选一，「回锋」「算力」「皮衣」三条流派互相咬合，构筑感强于数值堆叠
  3. **水墨硬核 × 中年喜剧**：宣纸墨晕的硬派视觉里，站着一个穿黑皮衣、银白背头、戴细框眼镜的五十岁刀客。他不年轻了，但皮衣比谁都贵
- Differentiation from competitors (compare genre experience only, no copying):
  同类多为西幻/赛博贴图风；本作用「水墨 + 皮衣」的错位感承接情绪，战斗对象是情敌而不是怪物，胜利奖励是「抢来的东西」——叙事与系统在内核上是同一个笑话。不做联网对战与抽卡池，纯单机买断。

## Characters

| 角色 | 一句话 | 造型要点 | 视觉锚点 |
|---|---|---|---|
| **老黄 / 黄大侠** | 年轻时靠「算力」打下半壁江山，如今刀不快了，眼睛还行 | 黑皮衣（高竖领）、银白背头、细框眼镜、瘦削、说话爱伸手指比划 | 全站唯一的纯黑皮革块面 + 飞白高光 |
| **阿岚** | 山脚茶棚的老板娘，老黄惦记了二十年没敢开口 | 素色袄裙、围裙、手上永远有面粉 | 不出镜，只在她被抬走时留下「一顶掉在雪里的斗笠」 |
| **三少爷** | 少庄主，年轻、有钱、会念诗、马比人高 | 层叠华服、朱砂腰带、长枪拄地、下巴微抬 | 关底唯一使用大面积朱砂的角色 |
| 九位情敌 | 从卖艺的到账房先生，个个觉得自己比老黄合适 | 各自一门手艺一件家伙，服装一律比老黄「新」 | 每一位对应一个刀诀奖励 |

## Story Spine（九场 · 桃花债）

```text
序：山脚茶棚，八抬大轿抬走了阿岚。老黄把茶钱压在碗底，起身。
一关 · 山门　　　　情敌 1–3：卖艺的 / 赶考的 / 打铁的　　　关底：铁面书生
二关 · 断桥雪渡　　情敌 4–6：镖师 / 道士 / 说书的　　　　　关底：白衣镖头 霍九
三关 · 少庄演武场　情敌 7–9：家丁头 / 账房先生 / 护院教头　关底：三少爷
终：山顶。阿岚在轿子里嗑瓜子，问他：「你怎么才来？」
```

- 每一关的关底情敌有**登场对峙**（2–3 句台词）与**专属血条**，其余六位在路线图上以节点形式遭遇
- 老黄的「皮衣」是护盾资源的名字：护盾归零时 UI 显示「皮衣已破」，这是全作最核心的一句双关
- 结局不做胜负二选一：赢了三少爷，阿岚自己走下轿子，说「我等你等到瓜子都嗑完了」

## Core Loop

```text
客栈 → 上山路线 → 遭遇（帮闲战 / 情敌战） → 战后三选一 → 继续上山 → 关底 → 下一关
```

| Stage | Player Goal | Main Screens | Success Criteria | 
|---|---|---|---|
| Return | 想起上次打到第几位情敌，决定接着打还是换打法 | `home` | 3 秒内看清「打到第几场 / 剩多少酒」，主按钮可点即走 |
| Prepare | 看清山道上哪个节点是下一个，这个人什么脾气 | `map` | 四个节点状态（已过/当前/未到/关底）一眼可辨 |
| Confront | 知道挡路的是谁、他凭什么挡路 | `rival-intro` | 台词读完 8 秒内可进入战斗，随时可跳过 |
| Core Gameplay | 用有限「气」打出招式，读敌人意图，撑过回合 | `battle` / `boss-battle` | 敌我血量、气、手牌同屏不遮挡；一次出招 ≤2 次点击 |
| Results & Progression | 拿走他一样东西，看到推进/阵亡结论 | `victory` → `map` | 三张牌面差异一眼可辨；跳过换酒只需一次点击 |
| Monetization Supply | 无内购；酒作为局内复活硬资源，靠通关与签到获得 | `home` / `settings` | 资源栏不制造焦虑，不做红点逼氪 |

## System List

| System ID | Name | Priority | Dependencies | Notes |
|---|---|---|---|---|
| SYS-BATTLE | 回合制对阵 | must-have | SYS-DECK, SYS-INTENT | 出招→敌意图结算→回合切换；老黄阵亡即局终 |
| SYS-DECK | 刀诀牌组与「气」 | must-have | - | 手牌 5 张，气 3 点/回合；牌 0–3 费 |
| SYS-INTENT | 敌方意图预告 | must-have | SYS-BATTLE | 敌头顶显示攻击/防御/蓄力图标与数值，硬核必需 |
| SYS-SHIELD | 皮衣护盾 | must-have | SYS-BATTLE | 独立于血量的护盾条，回合开始清零；破甲时 UI 改口「皮衣已破」 |
| SYS-BOSS | 关底情敌 | must-have | SYS-BATTLE, SYS-SHIELD | 单一目标、长血条四段刻度、阶段转换、专属嘲讽 |
| SYS-RIVAL | 情敌登场对峙 | must-have | SYS-BOSS | 2–3 句台词 + 性格标签，可跳过；读过可折叠 |
| SYS-RELIC | 战后三选一刀诀 | must-have | SYS-BATTLE | 三选一；跳过则换 1 点酒 |
| SYS-MAP | 山路路线图 | must-have | - | 每关四节点（三情敌 + 关底），点节点看详情再决定 |
| SYS-META | 局外积累：银两与酒壶 | genre-specific | - | 银两解锁初始刀诀，酒壶永久 +1 气上限 |
| SYS-SETTINGS | 设置与无障碍 | must-have | - | 音量 / 画质 / 震动 / 字号 / 语言 / 账号 |
| SYS-COLLECTION | 情敌名录（情敌与刀诀图鉴） | optional | - | 首版只做静态查阅 |
| SYS-DAILY | 每日一局 + 签到 | optional | SYS-META | 提供回访钩子，不阻塞首版 |

## Resources & Economy (Design Layer)

- Soft currency: **银两** — 局外解锁初始刀诀与客栈陈设；每战 +8~18，首通 +50
- Hard currency: **酒** — 局内复活（每局 1 次，消耗 2 酒）、跳过三选一换 1 酒；每日签到 +1，通九场 +3
- 成长货币: **声望** — 只用于情敌名录解锁与称号，不影响数值
- 护盾（皮衣）：不是货币，是每回合刷新的战斗资源，破甲后需靠「皮衣」类刀诀重铸

## Difficulty / Balance Notes

- 每位情敌有 1 条「性格标签」（话少 / 话多 / 有钱 / 轻敌），标签决定它的意图节奏：`轻敌` 前两回合不攻击，`话多` 每三回合浪费一回合念诗
- 关底情敌血量按 220 / 560 / 1000 递增，且第二形态护甲 +20
- 三选一稀有度权重：普通 60% / 稀有 32% / 传说 8%；关底战保底一张稀有
- 不做「自动战斗」，出招必须是玩家决策
