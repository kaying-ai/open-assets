# UI Research Notes

## Research Scope

- Project ID: `laohuang-battle`
- Subject of analysis: 竖屏手机肉鸽卡牌游戏的界面语言，以及「中式水墨」在可交互 UI 上的可落地做法
- Research goal: 找出一套能同时满足「硬核氛围」与「HUD 可读性」的水墨规则，避免做成贴图糊一层的水墨风皮肤

## Visual Abstraction of Reference Images

无外部分享的参考图。抽象来源为明清水墨人物册页（构图与留白）与硬核策略游戏 HUD（信息密度），只取规则不取画面：

- Color & contrast: 以**宣纸米黄为底、墨为骨、朱砂为血、金为赏**的四色体系。宣纸底让长时对战不刺眼；朱砂只承担「注意/伤害/主动作」，全页饱和色面积 <8%
- Materials & textures: 宣纸纤维（低频噪点 + 边缘微毛）、墨色晕染（多层半透明叠加 + 干笔缺口）、朱砂印泥（颗粒 + 边角不齐）、金箔（细颗粒高光）
- Lighting & shadows: 光源统一左上，硬度低。阴影不用黑色，用**墨青**（#2C3A38, 22%），避免水墨风里出现塑料感黑投影
- Corner radius, stroke & thickness: 圆角极小（4/8/12），模拟纸片裁切的硬边；描边 2/3/5 三档，主按钮用 5px 墨色外框 + 内 2px 亮线（模仿裱边）
- Composition density: 上疏下密——上部留白给氛围，信息压在拇指区。留白率目标 40%
- Icon perspective: 正视角、平涂墨块、单一光源，不做 3D 立体图标；所有图标统一 2.5px 笔触宽度
- Material contrast as identity: 全站只有老黄用「整片浓墨 + 飞白高光」的皮革块面，其余深色一律带墨晕层次。这条让「皮衣」成为可识别的角色符号，而不是一件衣服
- Reading the ground before choosing text color: 战斗页地面是亮雪，底部 HUD 因此改墨字 + 纸白小牌。**先判断背景明度再定字色**，比「战斗 HUD 一律反白」稳得多
- Typeface character: 标题用宋体骨架拉长字面（竖排更佳），正文用宋体常规字重；数字用等宽衬线以对齐血条与数值

## Reusable Patterns

- Navigation pattern: 首页底部四项「木牌」式导航，选中项朱砂下划线 + 实心图标；战斗页不挂底栏，改用双角入口（左暂停/右设置）
- Card pattern: 宣纸卡片 = 米黄底 + 1px 墨边 + 左上角朱砂小印 + 右下角枯笔飞白；卡片之间靠 24px 间距而非投影分层
- Feedback pattern: 飘字走「墨点炸开 → 数字上浮」；错误提示为顶部宣纸窄条（不是红色横幅），2.4 秒收起
- Information hierarchy: 数值 > 图标 > 装饰。数值永远用最长笔画对比（墨黑 on 米黄），装饰只用 30% 不透明度的墨晕

## Player Journey & Core Loop

1. First entry: 冷启动「磨刀中」→ 客栈首页，看到竖排 LOGO 与皮衣立绘，只有一个强动作
2. Preparation: 上山路线图，四个节点看清「打过谁、下一个是谁、他要说什么」
3. Confrontation: 关底节点 → 情敌对峙（2–3 句台词）→ 拔刀；跳过永远允许
4. Core gameplay: 读三个帮闲的意图按气量出牌；关底则面对单一情敌的长血条与阶段转换
5. Results & progression: 战后三选一「拿走他身上一样东西」，回路线图，节点推进一格
6. Daily return: 每日一局双倍银两；首页木牌提示「九场之五 · 断桥雪渡」，一指点回山道

## Risks & Constraints

- Copyright & brand: 老黄为原创中年刀客。造型取「黑皮衣 + 银白背头 + 细框眼镜 + 中年身形」的**组合语汇**做气质致敬，但不做任何真实公众人物的五官复刻、不使用其姓名/品牌/标志性配色；刀为通用雁翎/砍刀形制，不指向任何具体作品
- Portrait risk: 若后续要提高相似度，风险从「风格借鉴」滑向「肖像权」，需单独评估；本交付停在「气质像、脸不像」这条线上
- Text generation: 图像模型对中文毛笔字极易糊化 → **底图零文字**，所有中文由 HTML 排版层叠加，字体走系统宋体族
- Platform safe area: 竖屏顶部 56px（刘海/状态栏）、底部 96px（手势条）；主按钮最低边界距底 140px
- Complexity & development cost: 水墨滤镜（纸纹/墨晕）若在引擎内实时计算成本高 → 固化为静态贴图 + 9-slice，运行时只做位移与透明度

## Decisions

- Adopted:
  - 宣纸浅底 + 墨骨 + 朱砂点缀的四色体系（而非常见暗底发光 UI）
  - 底图 AI 生成 + UI 由设计系统确定性渲染（保证两态轮廓完全一致、9-slice 可切）
  - 组件按下态 = 压暗 14% + 顶缘内阴影，**几何完全不变**（缩放会让 9-slice 位移、透明边缘出缝）
  - 「底亮则字墨、底暗则字白」——按区域判断，不按页面统一
  - 叙事与系统同构：把「情敌」做成数据结构（rival），让路线图 / 对峙 / 关底战 / 三选一共用同一个对象
- Rejected:
  - 暗底霓虹方案：与「水墨」语义冲突，且长时对战眼疲劳
  - 纯毛笔字自动生成：中文必然糊，返工成本高于排版叠加
  - 战斗 HUD 一律反白：亮雪地上会糊成一团，v2 已改为按区域明度取字色
  - 情敌做成「更大的杂兵」：会丢掉叙事钩子，因此单独给了对峙页、长血条与阶段转换
  - 每页单独手绘控件：无法保证跨页一致，且 9-slice 切不出干净边
- Rationale: 硬核来自**对比与留白**，不来自暗色与发光；一致性来自同一份 tokens，而不是靠模型每次重新理解风格
