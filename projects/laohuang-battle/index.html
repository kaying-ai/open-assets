格式路径用途

工具链（kui）

命令作用
kui init laohuang-battle初始化 Spec-Kit 工作区
kui split sheet.png雪碧图 → 单元素 PNG + ZIP
kui atlas specs/laohuang-battle打包 Atlas PNG + JSON
kui export specs/laohuang-battle导出引擎 JSON
kui web specs/laohuang-battle生成 Web 交付 + result/index.html
kui validate specs/laohuang-battle --json契约校验
